# 公开源码说明

本项目记录 ChatGPT 桌面端数学公式显示补丁、Typeless 数学输入规范化和 Computer History 伴随链路。根目录 README 与受 MANIFEST 保护的资料保留历史原件；其中状态只对应记录日期。

`local-customizations/` 补充本机最新 Typeless 分支的工具和文档，排除了真实回执、日志与应用二进制。它与根目录的原始评审基线分开保存。

源码依赖具体 macOS 与应用版本，不能作为通用安装包直接运行。使用前先按各工具帮助核对版本；本次仅公开源码，不安装补丁、不操作 Computer History、不重新签名或启动应用。

公开仓库不分发官方应用、本地聊天和历史数据库、身份凭据或完整官方前端。Hammerspoon 浮窗与 Logi 控制的当前源码也会在独立项目中提供。
